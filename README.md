# Project Aligner

## Run locally
1. Install Node.js 20 or newer.
2. `npm install`
3. `cp .env.example .env.local` and paste your Anthropic API key.
4. `npm run dev` and open http://localhost:3000

## Deploy
Push to GitHub, import the repo at vercel.com/new, and add `ANTHROPIC_API_KEY` under Environment Variables.
